# Makro Hub 2.0 🚀

Hub de Gestão de Marketing e Operações da **Makro Engenharia**.

## Tecnologias
- **React 18** + **Vite**
- **Tailwind CSS** + **Hrivo Design System**
- **Firebase Firestore / Auth / Storage**
- **Phosphor Icons & Lucide Icons**
- **Recharts**

## Módulos
1. **Dashboard Executivo**: Resumos diários (*Today's Summary*), iniciativas e métricas gerais.
2. **Tarefas & Kanban**: Gestão operacional com atualização otimista e filtros inteligentes.
3. **Calendário Editorial**: Cronograma completo de publicações (redes sociais, revistas, artigos).
4. **Campanhas / Projetos**: Acompanhamento de grandes iniciativas de marketing com prazos e orçamentos.
5. **Documentos / Mídia Kit**: Repositório de identidades visuais, manuais e apresentações.
6. **Equipe**: Diretório da equipe de marketing.
7. **Performance**: Análise de produtividade, entregas e lead time.
8. **Configurações**: Gerenciamento de categorias, aparência e backups.

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
